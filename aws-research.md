# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform provided by Amazon. It offers a wide range of services that organizations can use for computing, storage, databases, networking, security, analytics, and artificial intelligence. AWS allows businesses to use cloud resources without having to maintain all of their own physical servers and infrastructure.

## Global Infrastructure

AWS has a large global infrastructure made up of Regions and Availability Zones. AWS Regions are separate geographic areas around the world, while Availability Zones are isolated locations within a Region. This infrastructure helps organizations deploy applications closer to their users and improve availability, reliability, and performance.

## Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services. Users can create and configure resources, monitor services, manage security settings, and view their AWS resources through the console.

## Four Core Services

### 1. Amazon EC2

Amazon Elastic Compute Cloud (EC2) provides virtual servers that organizations can use to run applications and workloads in the cloud.

### 2. Amazon S3

Amazon Simple Storage Service (S3) is an object storage service used to store files, images, videos, backups, datasets, and other types of data.

### 3. Amazon RDS

Amazon Relational Database Service (RDS) is a managed database service that makes it easier to create, operate, and scale relational databases.

### 4. Amazon VPC

Amazon Virtual Private Cloud (VPC) allows users to create a logically isolated network where AWS resources can securely communicate with each other.

## Three Advantages

1. **Wide Range of Services** - AWS provides many services for computing, storage, databases, networking, security, analytics, and artificial intelligence.

2. **Scalability** - AWS allows organizations to increase or decrease their cloud resources depending on their workload and demand.

3. **Global Infrastructure** - AWS provides infrastructure in many geographic locations, allowing businesses to deploy applications closer to their customers.

## Typical Enterprise Use Cases

AWS is commonly used by enterprises for hosting websites and applications, storing and backing up data, running databases, developing mobile applications, performing data analytics, and deploying artificial intelligence and machine learning workloads. Large organizations can also use AWS for disaster recovery and global application deployment.
